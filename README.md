# NQ News Terminal

Terminal tin tức NQ/QQQ kiểu Bloomberg — bản public trên GitHub Pages, port từ Space "NQ News Terminal" trong Muse (20/11/2026).

- `index.html` — trang terminal (wire tin thu gọn, bấm CHI TIẾT mới xem nội dung + nguồn; tự làm mới dữ liệu mỗi 60 giây)
- `news.json` — dữ liệu tin, được luồng canh tin của Muse cập nhật

Nguồn tin: ForexFactory / Turtle Hub News. Badge hướng giá là dự đoán tác động lên NQ/QQQ, không phải lời khuyên đầu tư.
